# 微信小程序体验版发布说明

本说明只用于“老妞大人宠宠我”微信小程序体验版。当前版本只给老哥和老妞两个人使用，暂不正式发布、暂不提交审核、暂不备案、不做 App Store、不做 iOS 签名、不使用企业证书或灰色证书。

## 1. 注册微信小程序账号

1. 打开微信公众平台：https://mp.weixin.qq.com/
2. 选择注册“小程序”。
3. 按页面提示填写邮箱、主体信息和管理员微信。
4. 注册完成后进入小程序后台。

## 2. 获取 AppID

1. 在微信公众平台后台进入“开发管理”。
2. 打开“开发设置”。
3. 复制小程序 AppID。
4. 替换 `laoniu-husband-miniprogram/project.config.json` 中的 `appid`。

默认占位值是：

```json
"appid": "touristappid"
```

## 3. 配置 CloudBase 环境 ID

1. 打开微信开发者工具。
2. 导入小程序后进入“云开发”。
3. 开通免费体验环境。
4. 复制环境 ID。
5. 替换 `laoniu-husband-miniprogram/src/services/cloud.ts` 中的：

```ts
export const CLOUD_ENV_ID = "your-cloudbase-env-id";
```

## 4. 创建云数据库集合

在云开发控制台创建以下集合：

- `users`
- `profile`
- `tasks`
- `rights`
- `logs`

建议体验版先把集合权限设置为“仅创建者可读写”或使用云函数读写；本项目的关键写操作都通过 `cloudfunctions/api` 完成。

## 5. 本地构建

在仓库根执行：

```bash
cd laoniu-husband-miniprogram
npm install
npm run build:weapp
```

构建产物在：

```text
laoniu-husband-miniprogram/dist
```

## 6. 微信开发者工具导入

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择 `laoniu-husband-miniprogram`。
4. AppID 填写你的真实小程序 AppID。
5. 编译目录使用默认 `dist/`。
6. 确认云函数目录为 `cloudfunctions/`。

## 7. 上传云函数

1. 在微信开发者工具左侧找到 `cloudfunctions/api`。
2. 右键选择“上传并部署：云端安装依赖”。
3. 部署完成后，在云开发控制台确认云函数 `api` 存在。

## 8. 上传体验版代码

1. 确认 `npm run build:weapp` 已生成 `dist/`。
2. 在微信开发者工具点击右上角“上传”。
3. 填写版本号，例如 `0.1.0`。
4. 填写项目备注，例如“老妞大人宠宠我体验版”。
5. 上传成功后进入微信公众平台后台。

## 9. 设置体验版

1. 微信公众平台后台进入“管理” -> “版本管理”。
2. 找到刚上传的开发版本。
3. 设置为体验版。
4. 生成体验二维码。

## 10. 添加老妞为体验成员

1. 微信公众平台后台进入“管理” -> “成员管理”。
2. 添加体验成员。
3. 输入老妞的微信号并确认。
4. 老哥作为管理员或开发者也可以扫码体验。

## 11. 体验范围说明

- 体验版只给老哥和老妞两个人使用。
- 暂不正式发布。
- 暂不提交审核。
- 暂不备案。
- 不购买传统服务器。
- 不使用 App Store、iOS 签名、企业证书或灰色证书。
- 如果小程序体验版不可用，现有 `husband-client` React/Vite/PWA 仍然保留为备用入口。

## 12. 验收清单

- 老哥 / 老妞可以手动绑定身份。
- 老妞可以发布任务。
- 老哥可以开始任务并提交完成。
- 老妞可以确认、驳回或判失败。
- 确认后经验、零花钱、等级、权益奖励能写入云数据库。
- 权益按等级解锁，卖身奴隶状态下置灰暂停。
- 老妞可以调整等级、经验、零花钱和卖身奴隶状态。
- 日志、圣旨、奖励流水进入 `logs` 集合。
