# 第二阶段 C：本地长期使用能力

本阶段保持 `laoniu-husband-miniprogram` 的 `DATA_MODE = "local"`，不依赖微信云开发。所有关键数据继续通过 Taro Storage 保存，方便先把完整业务迁移完，再回到 CloudBase 联调。

## 新增能力

1. 周期任务：支持 `once`、`daily`、`weekly`、`custom` 字段。
2. 任务模板：支持默认模板、新增、编辑、启用、停用、删除，以及发布任务时快速套用。
3. 今日待处理：老妞首页聚合任务确认、权益审批、卖身奴隶提醒、临期任务。
4. 老哥今日任务：老哥首页显示待完成、待确认、今日完成、今日失败。
5. 统计面板：按本月本地任务和日志计算任务、经验、零花钱、权益统计。
6. 本地数据备份：支持导出 JSON、复制、粘贴恢复、重置全部、清空任务、清空日志。
7. 数据版本迁移：当前版本为 `CURRENT_DATA_VERSION = 3`，旧数据会自动补齐模板和周期字段。
8. 设置页：显示数据模式、身份、openid、版本号、备份、日志、模板和身份重绑入口。
9. 日志页：支持最近 100 条日志查看、类型筛选和 JSON 详情。
10. 权益页增强：老哥可看可申请/冷却/锁定/待审批/记录，老妞可审批权益申请。

## 周期任务如何工作

周期字段保存在 `tasks`：

- `repeatType`: `once | daily | weekly | custom`
- `repeatRule`: 自定义周期说明
- `nextRefreshAt`: 下次刷新时间
- `lastGeneratedAt`: 上次生成时间
- `templateId`: 来源模板或周期母任务 ID
- `isGeneratedFromTemplate`: 是否由周期任务生成

进入首页或读取任务时会调用本地刷新检查。每日/每周任务只有在 `nextRefreshAt` 到达后才生成新任务；同一天已生成过的任务不会重复生成。`custom` 当前只保存字段和 UI 说明，复杂规则后续再实现。

## 任务模板如何使用

入口：

- 老妞首页 -> 任务模板
- 发布任务页 -> 常用模板
- 设置页 -> 任务模板

默认模板包括：今日表现任务、做饭、买东西、看电影、打游戏、拍照。模板可以停用或删除；停用后不出现在发布任务页的快速创建入口。

## 今日待处理如何计算

老妞首页的今日待处理来自本地数据：

- `submitted` 任务进入“任务确认”
- 权益 `pendingRequest` 进入“权益审批”
- 卖身奴隶状态进入“状态提醒”
- 24 小时内截止且未完成任务进入“系统提醒”

## 统计面板如何计算

统计从 `tasks / logs / profile / rights` 计算：

- 老哥端：本月完成任务、本月获得经验、本月获得零花钱、当前等级/经验/权益状态。
- 老妞端：本月发布任务、本月确认任务、本月发放经验/零花钱、待确认任务、待审批权益。

日期按本地时间的当月第一天开始计算。

## 本地数据导出与恢复

入口：设置页 -> 数据备份。

导出 JSON 包含：

- `version`
- `exportedAt`
- `profile`
- `tasks`
- `rights`
- `users`
- `logs`
- `templates`
- `settings`

恢复时会校验 JSON 格式。恢复、重置、清空任务、清空日志都会写入 `logs`。

## 数据版本迁移

`CURRENT_DATA_VERSION = 3`。每次读取本地数据库时会检查版本：

- 没有版本号时按旧数据处理。
- 低于当前版本时自动补齐 `templates/settings/repeat*` 字段。
- 迁移成功会写入 `system` 日志。
- 迁移失败会通过页面错误提示暴露，不让页面静默白屏。
